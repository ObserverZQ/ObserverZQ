# Hi, I'm Kerry 👋

I'm a Computer Science master's student at Columbia University, with a background in software engineering at miHoYo and Meituan.

I've always enjoyed building products that people use every day. My previous work focused on large-scale interactive applications, performance optimization, and developer tooling. At Columbia, I'm exploring how AI and HCI can make software more intelligent and useful.

### 🔭 What I'm working on

- **Graduate Compass:** A full-stack AI application for personalized graduate-program recommendations, combining hybrid retrieval, LLMs, and tool orchestration.
- **Code Review Agent:** Designing a multi-agent code review system for my Agentic Engineering final project, focusing on agent collaboration, tool orchestration, and evaluation.

### 🌱 What I'm learning at Columbia

- **[Agentic Engineering](https://course.nickgu.me/):** Building tool-using AI agents and exploring agent orchestration, multi-agent collaboration, and evaluation.
- **[Fundamentals of Large-Scale Distributed Systems](https://frankeh.github.io/cu-ds1-2026-fall/):** Studying scalable and fault-tolerant systems, including replication, consistency, and distributed coordination.
- **[Natural Language Processing](https://www.cs.columbia.edu/~johnhew/coms4705/index.html):** Learning foundational NLP methods, neural language models, and techniques for processing human language.
- **[Advanced Spoken Language Processing](https://www.cs.columbia.edu/~julia/courses/CS6706-26/syllabus26.html):** Exploring speech acoustics, phonetics, prosody, and speech recognition, with a particular interest in spoken language as a form of human-computer interaction.
