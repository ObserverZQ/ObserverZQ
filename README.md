# Hi, I'm Kerry 👋

I'm a Computer Science master's student at Columbia University, with a background in software engineering at miHoYo and Meituan.

I've always enjoyed building products that people use every day. My previous work focused on large-scale interactive applications, performance optimization, and developer tooling. At Columbia, I'm exploring how AI and HCI can make software more intelligent and useful.

### 🔭 What I'm working on

- **Graduate Compass:** A full-stack AI application for personalized graduate-program recommendations, combining hybrid retrieval, LLMs, and tool orchestration.
- **Agentic Engineering:** Exploring tool-using agents, orchestration, and evaluation.
- **NLP and Speech:** Learning how language and speech technologies can improve human-computer interaction.

### 🌱 What I'm learning at Columbia

- **Agentic Engineering:** Building tool-using AI agents, exploring agent orchestration, multi-agent collaboration, and evaluation.
- **Fundamentals of Large-Scale Distributed Systems:** Studying the principles behind scalable and fault-tolerant systems, including replication, consistency, and distributed coordination.
- **Natural Language Processing:** Learning how machines process and understand human language, from foundational NLP methods to modern neural language models.
- **Advanced Spoken Language Processing:** Exploring speech acoustics, phonetics, prosody, and speech recognition, with a particular interest in spoken language as a form of human-computer interaction.
